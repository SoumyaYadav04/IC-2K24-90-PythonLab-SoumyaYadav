## 2. Greeting Program
Aim: To take name, age and city as input and print a greeting.
Logic: The program takes three inputs from the user. It combines them into one sentence using an f-string.

Sample Input / Output:
Name → Soumya Yadav
Age → 18
City → Indore
Output → My name is Soumya Yadav, I am 18 years old, and I live in Indore.

## 3. Arithmetic Operations
Aim: To perform basic arithmetic operations on two numbers.
Logic: The program takes two numbers as input. It calculates their sum, difference, product, quotient and remainder.

Sample Input / Output:
First number → 10
Second number → 5

Output:
Sum → 15.0
Difference → 5.0
Product → 50.0
Quotient → 2.0
Remainder → 0.0

## 4. Celsius to Fahrenheit
Aim: To convert temperature from Celsius to Fahrenheit.
Logic: The program takes Celsius temperature as input. It uses the given formula to calculate Fahrenheit.

Sample Input / Output:
Celsius → 20
Fahrenheit → 68.0

## 5. String Manipulation
Aim: To perform different operations on a full name.
Logic: The program takes a full name as input. It changes the case, reverses the name and finds its length.

Sample Input / Output:
Name → Soumya Yadav
Uppercase: SOUMYA YADAV
Lowercase: soumya yadav
Reversed: vadaY aymuoS
Length: 12

## 6. Escape Sequence Practice
Aim: To print a simple receipt using escape sequences.
Logic: The program uses `\\t` for spacing and `\\n` for new lines. It prints the items and their prices in a simple format.

Sample Output:
Item → Price
Pen → ₹10
Notebook → ₹50
Pencil → ₹5
Total → ₹65
